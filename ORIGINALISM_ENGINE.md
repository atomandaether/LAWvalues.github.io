# Originalism classification engine

This file records the locked algorithmic architecture for Originalism.  Public explanatory copy can change later without changing this taxonomy.

## Public nouns

The classifier may publicly return:

- **Public-Meaning Originalist**
- **Original-Intent Originalist**
- **Originalist** only as a fallback when historical fixation is clear but the OPM/OI target cannot be resolved.

`Original-Methods Originalist` and `Framework Originalist` remain internal/legacy theory labels only.  They must not win as public nouns.

## Modifier layer

**New** is the substantive Originalist modifier.  It means the respondent accepts the interpretation/construction distinction: fixed original meaning can genuinely underdetermine a case and leave legitimate room for constitutional construction.

It may attach to either public noun:

- **New Public-Meaning Originalist**
- **New Original-Intent Originalist**

A second substantive Originalist hybrid is **Higher-law**. It is reserved for natural-law-grounded Originalism: objective morality plus the settlement authority of positive constitutional law. It is not triggered by generic non-positivism. The locked Pojanowski / Walsh / Alicea / Strang unit is the canonical **Higher-law Public-Meaning Originalist** endpoint.

The OI+construction cell is principally represented by Keith Whittington.  The OPM+construction cell contains several champion units.

When no substantive modifier applies, generic fit language is used:

- **Unmistakably a/an [noun]** for an unusually clean, well-separated match.
- **[noun]** for the deliberately narrow middle band.
- **Some kind of [noun]** for a weak, mixed, or close nearest-neighbor match.

Current fit gates are theory-derived rather than population-calibrated: Unmistakably requires identity score >= .82 and margin >= .07; Some kind of applies below .72 or with margin < .04.

## Adaptive diagnostics

The global quiz still caps adaptive questions at seven per respondent.  Originalism therefore uses diagnostics only when they can change a live classification.

- **D-ORI1** — public meaning versus original intent; noun-level router.
- **D-ORI3** — construction; drives the **New** modifier and Whittington/New-OPM routing.
- **D-ORI4** — only for unresolved OI cases; separates modern semantic intentionalism from the Bork/Berger restraint package.
- **D-ORI2** — only on the OPM side when useful; Original Methods evidence for McGinnis/Rappaport.
- **D-ORI5** — lower-priority OPM specialist question for Amar-style intratextualism.

The 88-item core already supplies most remaining champion evidence: textual constraint, rules and anti-discretion, principle versus expected applications, early practice, precedent correction versus settlement, majoritarianism, rights enforcement, separation formalism, and natural-law/source commitments.

## Reachability contract

The audit suite requires all thirteen champion units to be separately selectable under coherent fixtures, requires OPM/OI to be the only public Originalist children, requires **New** to appear for constructionist OPM/OI, requires **Higher-law** for the natural-law-grounded Originalist cell, and verifies Unmistakably / blank / Some kind of fit states.
